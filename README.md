# Excel Abacus Website

This is a responsive single-page website matching the supplied Excel Abacus design direction:
- Emerald green + sunshine yellow brand palette
- Desktop and mobile responsive layouts
- Home, About, Courses, Achievements, Events and Contact sections
- Mobile hamburger menu
- Admission/enquiry form front-end behavior
- Photo placeholders are intentionally included so your real class, teacher and winner photos can be added later

## Files
- index.html
- styles.css
- script.js

## Before publishing
1. Replace the photo placeholder blocks with your real images.
2. Replace the map placeholder with a Google Maps iframe for the exact location.
3. Connect the enquiry form to WhatsApp, email, Formspree, PHP, or your preferred backend.
4. Add your real Facebook/Instagram/YouTube URLs.
5. Replace the text details if any course/event information changes.

For GitHub Pages, upload all three files to the repository root and enable Pages.
